Task Studio
Design foundation  ·  2 September 2026

Editorial typesetting: paper and hairline rules rather than cards and shadows. No rounded corners, no shadows, no icons beyond what is necessary. Everything here is lifted from app/globals.css and components/ui.tsx, not designed alongside them.

Type

Bodoni Moda for display and for numbers meant to be read. Archivo for everything else. Both are loaded through next/font/google, so there is no network call at runtime. This canvas cannot reach Google Fonts, so it renders the same fallback stack the app falls back to: Didot and Helvetica Neue.

Status marks

A 7 px square plus a word, and the two always say the same thing. Never colour alone: the word carries the meaning and the mark only makes the row scannable. Six of these are a status you choose. «Blocked» is not. It left the enum on 2 September 2026 and is derived: a node is blocked exactly when it carries an open blocker, computed in v_node_state and never stored. The word shown is therefore the effective state, with the day count beside it.

Progress

Drawn as cells, not as a bar. One cell per task in the subtree, so the shape itself says how much work the number is standing on. Above 24 tasks the cells would be thinner than a rule, and it falls back to a single bar. Never editable: it is a view.

The grid

Every page in the app is the same three columns: a 184 px label gutter, a flexible middle, a 420 px right column carrying the pulse. Hairline rules separate them. The page ground shows through; nothing floats on top of it.
